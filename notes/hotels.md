# Hotels

Which films feature which hotel, so a new film can avoid repeating the same shots. Check the film's note for
the exact clips and photos used. [All films](README.md) · [Music](music.md)

Standing rules on shots:
- Never use the Kingfisher river or roast table clips again (Scott: "stop using that same kingfisher clip").
- Gisborough only on its best shots (the ivy and frosty terrace are "not inspiring").
- No festive decor outside the Christmas films; the Kingfisher's tree, garland and fire clips are kept for the festive reel.
- Not Fairlawns again for a while (Scott, 20 Oct, on the UI explainer).
